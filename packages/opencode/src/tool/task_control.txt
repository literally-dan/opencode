Inspect or stop subagent tasks owned by the current session.

Use action="list" to see the live descendant tree, including execution phase, current tool, last activity, result-delivery state, and detached work. Use action="stop" with a task_id to cancel that task and its active descendants. You cannot view or stop siblings or unrelated sessions.

Use scope="ancestors" only when this task was spawned with read-only ancestor status access. Ancestor access never grants stop permission.

Do not poll repeatedly. Query when you need to reconcile missing completion, investigate quiet work, or inspect the current task tree. Task results are still delivered automatically.
